# Обои ARGVUS

`argvus-wallpapers` устанавливает два основных обоя для рабочего стола: один тёмный и один светлый. Каждая официальная тема поставляется со своими обоями, поэтому обои активной темы обычно соответствуют самой теме, а не этим.

## Установленные файлы

| Файл | Формат |
| --- | --- |
| `/usr/share/backgrounds/argvus/argvus-dark.jxl` | JPEG XL |
| `/usr/share/backgrounds/argvus/argvus-light.jxl` | JPEG XL |
| `/usr/share/backgrounds/argvus/argvus-dark.svg` | СВГ |
| `/usr/share/backgrounds/argvus/argvus-light.svg` | СВГ |

Пакеты тем добавляют свои обои в директории `/usr/share/backgrounds/argvus/abstract/`, `dark` и `light`.

## Выбор обоев

Откройте Центр управления (Внешний вид > Обои). Первый пункт открывает выбор файла для вашего собственного изображения. Пользовательские обои сохраняются как `/appearance/wallpaper` вместе с `/appearance/wallpaper_custom` в `config.json`. Выбор встроенных обоев заменяет пользовательский выбор; это не меняет тему.

Установка пакета не добавляет никаких каталогов в селектор обоев: селектор предлагает встроенные обои и возможность выбрать собственное изображение.
