# ARGVUS Wallpapers

A coleção de Wallpapers do ARGVUS inclui wallpapers de alta qualidade, profissionalmente projetados, que complementam a identidade visual do ambiente desktop ARGVUS.

## Coleção de Wallpapers

A coleção oferece:
- Designs abstratos minimalistas
- Cores coordenadas com temas ARGVUS
- Múltiplas resoluções (1920x1080, 2560x1440, 3840x2160, etc.)
- Variantes claras e escuras

## Instalação

Os wallpapers estão disponíveis através de:

```bash
pacman -S argvus-wallpapers
```

## Definir Wallpapers

Defina seu wallpaper através de:
- ARGVUS Control Center → Appearance → Wallpapers
- Menu de contexto da área de trabalho
- Configurações do sistema

## Localização

Os wallpapers instalados estão localizados em:
- `/usr/share/pixmaps/argvus-wallpapers/`
- `~/.local/share/pixmaps/` (wallpapers personalizados do usuário)

## Wallpapers Personalizados

Você pode adicionar seus próprios wallpapers colocando-os em `~/.local/share/pixmaps/wallpapers/` e eles aparecerão no seletor de wallpapers.
